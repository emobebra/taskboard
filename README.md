# TaskBoard

Дошка завдань — навчальний наскрізний проєкт із дисципліни «Технології створення вебзастосунків».

## Автор

- Ім'я: Успенська Емілія
- Група: ІПЗ-3/2

## Про проєкт

TaskBoard — навчальний вебзастосунок для керування завданнями. У майбутньому система дозволятиме створювати завдання, встановлювати їхні статуси та відстежувати виконання. Проєкт розробляється поетапно протягом курсу.

## Технології

| Шар | Технології |
|---|---|
| Frontend | HTML, CSS, JavaScript |
| Backend | Python, Flask (планується) |
| База даних | SQLAlchemy, PostgreSQL (планується) |
| Розгортання | Docker (планується) |

## Як запустити

1. Склонуй репозиторій:

```bash
git clone https://github.com/emobebra/taskboard.git
```

2. Відкрий папку проєкту у VS Code.
3. Запусти файл `index.html` у браузері або через Live Server.

## Скріншот

Скріншот головної сторінки буде додано до папки `images`.
