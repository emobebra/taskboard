## запитання та відповіді на них

**1. Що змінилося у виводі git status після git add?**

Після виконання git add файл перейшов до розділу Changes to be committed, тобто був підготовлений до коміту

**2. Що показує git diff?**

Команда git diff показує зміни у файлах. Додані рядки позначаються знаком +, а видалені — знаком -

**3. Чим відрізняється git switch main від git merge?**

Команда git switch main перемикає на основну гілку, а git merge об'єднує зміни з іншої гілки з поточною

**4. Чому виник конфлікт і як ти його розв'язала?**

Конфлікт виник через зміну одного заголовка у файлі index.html у двох різних гілках. Я вручну відредагувала конфліктний фрагмент, залишила узгоджений заголовок і завершила злиття
